# AI-Powered Rescue Drone

## Problem Statement
During disaster situations, locating victims can be difficult
and dangerous for rescue teams.

## Solution
Our AI-powered autonomous rescue drone helps search for victims
and hazards using AI-based detection, RGB and thermal cameras,
GPS tracking and emergency alerts.

## Key Features
- AI-based person detection
- RGB camera monitoring
- Thermal camera support
- GPS location tracking
- Hazard detection
- Emergency alert system
- Rescue monitoring dashboard

## Technologies Used
- HTML
- CSS
- JavaScript
- AI/Computer Vision
- GPS
- RGB Camera
- Thermal Camera
- Drone Technology

## How It Works
1. Drone starts the rescue mission.
2. Cameras capture the environment.
3. AI detects people and hazards.
4. GPS records the detected location.
5. Alert is sent to the rescue team.
6. Rescue team can monitor the mission through the dashboard.
